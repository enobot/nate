# Screenshots to capture

No screenshots are in this folder yet. Capture these from the running local demo
(http://localhost:5201) and save them here with the file names below, so the main README
can link to them.

Before you start: open **About this demo** and click **Reset demo data** so every screenshot
shows the same starting data. Use a desktop browser window about 1440 px wide unless noted.

| File name | Page and what to show |
| --- | --- |
| `01-dashboard.png` | **Dashboard** with the stat cards, the three bar charts and the newest requests table visible. |
| `02-assets-list.png` | **Assets** filtered to Status = Deployed and Type = Laptop, sorted by Warranty ends. |
| `03-asset-form-errors.png` | **Add asset** after clicking the submit button on an empty form, so the error summary and red field messages show. |
| `04-asset-detail.png` | An asset detail page that has at least two entries in **Assignment history**. |
| `05-network-switches.png` | **Network > Switches** showing the switch cards with port utilization bars. |
| `06-switch-ports.png` | A switch detail page (for example ENG-IDF1-SW01) showing the ports table with patched jacks, VLANs and the last port labelled **Uplink**. |
| `07-activate-jack.png` | **Network > Jacks**, the **Activate** dialog open on an inactive jack in ENG, with a switch, free access port and VLAN selected. |
| `07b-no-free-ports.png` | The **Activate** dialog for an ADM jack (for example 1-113A), showing "No free access ports on ADM-IDF1-SW01". |
| `08-requests-list.png` | **Service requests** with "Open only" and Priority = P2 filters applied. |
| `09-request-detail.png` | A request detail page showing the workflow buttons, assignment card and the history timeline. |
| `10-resolve-notes.png` | The same request after clicking **Resolve**, with the resolution notes box visible. |
| `11-reports.png` | **Reports** with the warranty report and one report's **Show SQL** panel open. |
| `12-mobile-dashboard.png` | The dashboard at phone width (about 390 px) with the **Menu** button visible. |

Tips:

- Windows: press `Win + Shift + S` (Snipping Tool) to capture a window or region.
- Crop out browser bookmarks and anything personal.
- PNG keeps text sharp; keep each file under about 500 KB if possible.
